## Правила, которые дороже всего дались

- **Сверка берёт дату не моложе двух суток.** Начисления доезжают.
- **Знак — часть значения.** `abs()` на деньгах запрещён.
- **Никакого молчаливого `else`.** Незнакомый тип называется вслух.
- **Имя вместо проверки.** `external_promo`, а не `advertising_external`.
- **Два числа с разницей объясняются в той же строке** — или отчёт не выпускается.
- **Необратимое — только по слову на план с числами.** Выполняет его та сессия, которая показала план.
