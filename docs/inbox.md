### 4. Площадки на заказах

Листы «Заказы Основная», «Заказы Селект», «Заказы Дискаунтер» — как листы
площадок у выкупов: создано / подтверждено сейчас / отменено / ещё
отменится / прогноз подтв. / комиссия (доля по площадке уже измерена) /
выручка / СС / маржа, плюс справочно «создано × 0,59 / НДС» и «Маржа
(созданных)». Реклама и фин. рез. — только на общем листе (леджер без
площадки), как и сейчас. Площадка товара — та же карта, что у выкупных
листов; «Без площадки» — отдельной строкой в итогах, не молча.

В `--check-orders` добавить сравнение по площадкам: его «Заказы Standard»!B
против нашей Основной, «Ozon Select»!B против Селекта, «Ozon
Дискаунтер»!B против Дискаунтера — по дням, отношение его/наша по каждой.
Это и есть способ найти −8 %: если у Селекта отношение ≈ 1, а у Основной
≈ 0,9 — разница сидит в комиссии его источника; если у всех ≈ 0,92 — в
ценах. Только напечатать и назвать, не чинить.
