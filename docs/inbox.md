### §4. Соинвест неизмеренных строк заказов — по выкупам месяца (ветка `finrez-coinvest-fill`, поверх §2)

Сейчас «СПП %» и «Заказы, руб c СПП» заполнены только там, где измерена цена покупателя (Ozon с 09-01); у остальных строк
пусто — в сводной владельца на наших данных они входят как 100 % соинвеста. Сделать:

1. **Ozon**: доля соинвеста месяца по выкупам = Σ (bonus + coinvestment) / Σ seller_price по `marketplace_buyouts` месяца
   (по площадке Ozon в целом; помесячно апрель … сентябрь — числа в отчёт: сентябрь должен быть ≈ 53,5 % как в утренней
   книге). Для строк без измеренной цены: «Заказы, руб c СПП» = «Заказы, руб без НДС» × (1 − доля месяца), «СПП %» = доля
   месяца. **WB**: доля месяца по отчёту реализации = (Σ retailPriceWithDisc − Σ retailAmount) / Σ retailPriceWithDisc по
   `saleDt` месяца (формула P владельца, модуль WB её знает — если в контракте нет функции, посчитать у себя из
   `wb_sales_report_rows` строк «Продажа», без правки WB-файлов); подставить так же всем строкам WB.
2. Пометка источника: новая колонка справа среди наших добавок — «СПП источник» = «измерено» / «по выкупам месяца»; в
   «Примечаниях» — правило. Измеренные строки не трогать.
3. Приёмка: «Свод» Соинвест % по месяцам — теперь заполнен у всех меток обоих блоков; по Ozon сентябрь = прежнему
   значению по измеренным строкам до 0,01 п. п. (измеренных там 100 %); апрель … август Ozon и все месяцы WB = доле
   месяца по выкупам (по построению) — таблица в отчёт; остальные 12 колонок «Свода» — 0,00 против 40-й.
