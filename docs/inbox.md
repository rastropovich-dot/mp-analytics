Доказано в пятнадцатой: в `accrual/postings` строка типа 69 `SaleCommission`

* миграция `sql/20260921_add_buyouts_units.sql`: `marketplace_buyouts.buyouts_units integer null`

  дат окна берёт номера отправлений с продажей из by-day (тот же ответ,

  штуки по (дата, sku) со знаком, `update` только колонки `buyouts_units`
  у существующих строк. Строка выкупа без штук и штуки без строки —
  считать и печатать, не молчать. Оценка обращений — назови до первого
  запуска; ориентир — 30-дневное окно ≈ 5–6 тыс отправлений ≈ 25–30 вызовов;
* посев истории: сырьё `data/accrual_postings/` (три файла, 03-28 … 09-15) +
  доснять 09-16 … вчера; план — строк с штуками, Σ штук по месяцам против
  таблицы пятнадцатой (итого 43 814 штук / 43 315 позиций за 170 дат),
  `--apply` по слову;
* генератор: себестоимость по штукам, где `buyouts_units` не null, иначе
