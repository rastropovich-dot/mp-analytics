### §2. Расчёт в `unit_cost_history`

`loaders/unit_cost_history.py`: `CostHistory` получает таблицу курсов и k по категориям (из профиля кабинета: `cabinets/karatov.py` — `COST_RATE_K` по категориям и пробам; у `rbh1`/`rbh2` — «не задано» → без поправки, источник «снимок»); `cost_source(norm, day, qty)` → (СС, источник), где СС = снимок ≤ day × (1 + k × Δ), Δ = курс 1С металла на day / курс на дату снимка − 1; проба и категория — из строки снимка (`metal_fineness`, `product_kind` / категория владельца через `ozon_products`); нет пробы — без поправки, счётчик «без пробы».
