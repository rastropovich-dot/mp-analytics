# Входящая задача

Сюда советник кладёт задачу для рабочей сессии. Сессия читает этот файл
и выполняет то, что в нём написано, а отчёт пишет в `docs/outbox.md`.

Порядок: одна задача за раз. Прежде чем взять новую, убедись, что по
предыдущей отчёт уже написан. Файл переписывается целиком, истории в
нём не копится — след остаётся в git.

**Пока задача в работе, советник этот файл не трогает.**

Если задача противоречит правилам из `CLAUDE.md`, выполняется
`CLAUDE.md`, а расхождение описывается в отчёте.

### 1. Пересборка

```
venv/bin/python3 scripts/rebuild_ozon_orders_history.py --apply --date-from 2026-03-28
```

Контрольные числа из плана — назови фактические рядом с ними:

```
строк                       57 256 → 60 654
подтверждённые Ozon    1 434 985 797 → 1 116 800 429
ступенька 08-18            9 910 881 → 7 403 969   при 08-19 = 7 655 901
```

Если `delete` 36 410 строк упрётся в `statement_timeout = 8 s` —
запрос откатится, записи не будет; тогда дели удаление на части по
месяцам и скажи об этом в отчёте. Не обходи таймаут увеличением
лимитов на стороне БД.

Начинать только если до 00:15 UTC остаётся не меньше часа. Скрипт сам
не стартует в 00:15…03:15 — не обходи эту защиту.

### 2. Сразу после, тем же заходом

Удалить 479 ключей `daily_sku_kpi` за 04-02 … 04-28 на 17 031 211 ₽ по

не перестроит, и без этого апрель останется задвоенным. Остальные 372
ключа не трогать — их перепишет ночь.
