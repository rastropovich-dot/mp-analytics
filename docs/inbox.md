Сюда советник кладёт задачу для рабочей сессии. Сессия читает этот файл
и выполняет то, что в нём написано, а отчёт пишет в `docs/outbox.md`.

Порядок: одна задача за раз. Прежде чем взять новую, убедись, что по
предыдущей отчёт уже написан. Файл переписывается целиком, истории в
нём не копится — след остаётся в git.

**Пока задача в работе, советник этот файл не трогает.**

Если задача противоречит правилам из `CLAUDE.md`, выполняется
`CLAUDE.md`, а расхождение описывается в отчёте.

### 1. Лист «Ozon - <месяц>» — по дням и итого

```
колонка                 источник                                           НДС
Оборот                  marketplace_buyouts, сумма продаж дня              как есть (с НДС, как в листе)
Комиссия                marketplace_buyouts.commission_amount              как есть
Выручка                 (Оборот − Комиссия) / 1,22
Себестоимость           article_unit_costs (снимок 05-20) × позиции выкупов — по решению 4; sku → article как в сверке
Маржа, Маржа %          Выручка − СС;  / Выручка
Логистика               marketplace_expenses, статья logistics             / 1,22
Эквайринг               тип 1                                              / 1,22
Подписка                статья subscription (тип 51)                       / 1,22
Реклама                 типы 41 + 54 из сырья accrual by-day (п. 2)        / 1,22
ДРР %                   Реклама / Оборот  — от оборота, как в листе
Прочее                  статья other + external_promo без типа 1           / 1,22
Фин. рез., %            Маржа − Логистика − Эквайринг − Подписка − Реклама − Прочее;  / Выручка
справочно               «Реклама по образцу» (41+54+51+96)/1,22; «Логистика + Прочее по образцу» = (наши Л + П + Подписка + тип 96)
```

НДС — не константа в формуле, а параметр с датой действия (1,22 сейчас;
`reports_model.md` §4), чтобы лист декабря 2025 с 1,2 не потребовал
правки кода. Даты моложе двух суток помечай в листе: начисления доезжают
(правило из `STATUS.md`).

### 5. `ORDER BY` в `reports_daily_sku_kpi.py`

how-we-work за 15 сентября, ты сама назвала его первым подозреваемым.

первичный ключ), ветка, тест на то, что каждый запрос уходит с `order`.

«вопрос, задача не закончена». Предсказание на ночь после мержа:
витрина = таблице по всем датам, как 09-19, — изменений в числах ноль.
