### §2. НДС в «Данных Ozon выкупы»: четыре статьи без НДС, оборот и комиссия с НДС — как у аналитика владельца

Разобрано с владельцем 09-28. В его образце («Фин рез … Озон Выкуп») сводная получает данные из Power Query; в запросе
«Фин начисления» (customXml → DataMashup → `Formulas/Section1.m`, шаг «Добавлен пользовательский объект1»):

```
Начисления = if [Статьи Озон.Вид затрат] = "Логистика" or "Реклама" or "Прочее" or "Эквайринг"
             then [Сумма итого, руб.] / 1.22
             else [Сумма итого, руб.]            ← Товарооборот и Комиссия остаются с НДС
```

Поэтому его формулы рядом со сводной (W = −D, Y = −H, AA = −L, AC = −F; S = (P − Q) / 1,22) правильны только на источнике
без НДС у этих четырёх статей. Наш лист «Данные Ozon выкупы» отдаёт сводной все начисления с НДС (по знаку — как у владельца,
по НДС — нет); отсюда единственное расхождение прогона 3в: AD у сводной Ozon меньше «Фин. рез.» листа «Выкупы Ozon» на
0,22 × расходов (апрель −3 225 285,47). API Ozon отдаёт суммы с НДС — доказано пятнадцатой (ручной отчёт × 1,22 = наши типы,
CLAUDE.md «Логистика 1–9 июля — объяснена»).

Сделать в `scripts/report_finrez.py` (строки «Данные Ozon выкупы»): для строк с видом затрат Логистика / Реклама / Прочее /
Эквайринг колонку начислений делить на ставку НДС **по дате начисления** (как на «Ozon - месяц», функция проекта, не константа
1,22), знак прежний; Товарооборот и Комиссия — без изменений. **Себестоимость не делить**: наш снимок 1С `cost_20260520` уже
без НДС (слово владельца 09-28; у аналитика делится его собственный источник с НДС — к нам не относится). Заголовок листа
данных и «Примечания» — переписать («статьи расходов без НДС по дате, оборот и комиссия с НДС, как в запросе владельца»).
WB-данные и формулы WB не трогать (там НДС снимают его формулы R, T, X — источник с НДС и должен таким остаться);
«Данные заказы» не трогать (там «без НДС» уже в колонках).

Проверки: (а) статичные листы «Выкупы Ozon», «× бренд», «× категория», «Коэффициенты», «Заказы» — до и после **0 разниц по
всем ячейкам** (они уже считают без НДС; если `svod_from_data` строит их из строк данных — не дать разделить дважды);
(б) `finrez_excel_check.py`: ожидание для AD меняется с «Фин. рез. − 0,22 × (Л + Р + Э + П)» на **AD = «Фин. рез.» листа
«Выкупы Ozon» по месяцам, 0,00 за все шесть месяцев**; W / Y / AA / AC = колонки без НДС статичного листа, 0,00; P … U как
были; WB 42 / 0 без изменений; (в) блоки листа «Артикул» по статьям расходов — теперь без НДС, сверка с данными 116 / 0 держится;
(г) сумма «Начислений» по статье за месяц в данных × 1,22 = прежняя сумма с НДС (контроль деления, по месяцам, в отчёт).
