# Входящая задача

Сюда советник кладёт задачу для рабочей сессии. Сессия читает этот файл
и выполняет то, что в нём написано, а отчёт пишет в `docs/outbox.md`.

Порядок: одна задача за раз. Прежде чем взять новую, убедись, что по
предыдущей отчёт уже написан. Файл переписывается целиком, истории в
нём не копится — след остаётся в git.

**Пока задача в работе, советник этот файл не трогает.**

Если задача противоречит правилам из `CLAUDE.md`, выполняется
`CLAUDE.md`, а расхождение описывается в отчёте.

### 1. Лист «Заказы» — прогноз без зашитых коэффициентов

У владельца (`reports_model.md` §1): ДРР = Реклама / (Выручка × 0,65 × 1,22
/ 0,59), Фин. рез. = Маржа × 0,65 − Реклама − Выручка × 0,65 × 0,024.
Три константы — выкупаемость, доля после комиссии, доля прочих. У нас все
три измеряются. Лист по дням D месяца, отдельно FBO и FBS и итого:

```
создано              orders_* + cancelled_* из marketplace_orders (шт, ₽)
подтверждено сейчас  orders_*;  отменено сейчас — cancelled_*
возраст              сегодня − D
ожидаемые отмены     по кривой дозревания: c(age) — срез 09-15 (reports_model §5), плато — по дозревшим
                     месяцам пересборки, по схеме (FBO 39,9–42,4 % шт, FBS 43,6–48,4 %; двадцать вторая);
                     доля ещё не пришедших отмен = (c∞ − c(age)) / (1 − c(age)); для age ≥ 21 — факт, прогноза нет
прогноз подтв. ₽     подтверждено сейчас × (1 − доля ещё не пришедших)
комиссия             измеренная доля за последние 30 дней из marketplace_buyouts (не 0,41), по схеме
выручка прогноз      прогноз подтв. × (1 − доля комиссии) / 1,22
СС                   article_unit_costs по SKU дня × прогноз подтв. шт
маржа                выручка − СС
реклама              факт дня: 41 + 54 из леджера (двадцать шестая)
ДРР                  от созданного ₽ и от прогноза подтв. ₽ — две колонки
прочие               измеренная доля (логистика + эквайринг + подписка + прочее) / оборот за 30 дней, по схеме
фин. рез. прогноз    маржа − реклама − прочие
справочно            формулы владельца на его константах — рядом, чтобы разница была видна
```

Приёмка — на дозревших датах: для D старше 21 дня прогноз подтв. = факт
(доля ещё не пришедших = 0); для июля Σ «фин. рез. прогноз» рядом с Σ
«фин. рез.» выкупного листа за тот же месяц — числа разные по природе
(дата заказа против даты реализации), но порядок обязан совпадать;
расхождение — с объяснением в той же строке. Кривая — с датой среза в
шапке листа: продольная по когортам придёт к середине октября, тогда
лист пересчитается сам.
