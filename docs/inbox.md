### §2. «Данные заказы» и «Заказы» — по формулам вычисляемых полей сводной владельца

Советник дочитал кэш его сводной заказов (`data/owner_finrez_orders_pivot.xlsx`, `pivotCacheDefinition`): восемь полей —
вычисляемые (`formula=`), считаются Excel-ем **на суммах** полей источника:

```
Маржа, руб без НДС   = 'Выручка, руб без НДС с учетом комиссии' − 'Себ-ть Реал'
Маржинальность, %    = Маржа / Выручка
ДДР, %               = 'Реклама, руб без НДС' / Выкуплено
Соинвест, %          = ('Заказы, руб без НДС' − 'Заказы, руб c СПП') / 'Заказы, руб без НДС'
Комиссия сред        = 'Комиссия, руб' / 'Заказы, ₽'
Фин.рез              = Выкуплено − 'Себ-ть Реал' × (Выкуплено / Выручка) − 'Реклама, руб без НДС'
Цена                 = 'Заказы, ₽' / 'Заказы, шт'
Фин.рез %            = Фин.рез / Выкуплено
```

и поля листа «Свод»: Оборот (с НДС) = Заказы ₽ · Заказы шт · Цена продавца = Цена · Комиссия % = Комиссия сред · Выручка =
'Выручка …' · Себестоимость = 'Себ-ть Реал' · Маржа · М-ть % · Реклама = 'Реклама, руб без НДС' · ДДР % · Соинвест % ·
Гр.фин.рез = Фин.рез · Гр.фин.рез % = Фин.рез %. Отсюда семантика источника: **«Выручка» и «Себ-ть Реал» — по всем созданным
заказам, без коэффициента выкупа; «Выкуплено» — рубли = Выручка × коэффициент** (в образце май: Выкуплено / Выручка = 0,843 =
его коэффициент; ДДР и Фин.рез % делятся на него как на деньги); коэффициент входит только в Фин.рез. У нас сейчас
коэффициент вложен в Выручку, Себестоимость и Маржу, а «Выкуплено» в «Данных» — коэффициент 0,63: его сводная на наших
данных посчитала бы ДДР и Фин.рез в ерунду, а статичный лист разошёлся бы с ней в коэффициент раз по трём колонкам.

1. **Строка «Данных заказы» (21 поле источника, порядок и имена как сейчас):** Заказы ₽ · Заказы шт · Реклама ₽ · Себ-ть Реал
   = СС × шт × индекс (все заказы) · Наименование · Бренд · Статус · Заказы без НДС = ₽ / 1,22 · Реклама без НДС = Реклама / 1,22
   · СПП % и Заказы с СПП (Ozon где измерено, WB пусто — как сейчас) · Комиссия = коэффициент площадки за месяц (наша
   фактическая; WB 0,42) · **Выручка = Заказы без НДС × (1 − Комиссия)** — без коэффициента выкупа · **Комиссия, руб = Заказы ₽
   × Комиссия** (так его «Комиссия сред» = Комиссия руб / Заказы ₽ покажет коэффициент; проверено по образцу: сентябрь его
   0,5017 при ставках 0,23 / 0,52 возможен только на базе с НДС) · **Выкуплено = Выручка × коэффициент выкупа площадки** (Ozon
   62,98 %, WB 49,81 % — «Коэффициенты») · Неделя года · День; «Месяцы» — 30-я, как в 39-й. Наши восемь одноимённых колонок
   22 … 29 — **ровно по его формулам построчно** (Фин.рез = Выкуплено − Себ-ть × (Выкуплено / Выручка) − Реклама без НДС и т. д.),
   чтобы читатель «Данных» видел то же, что его сводная; наши добавки справа как были.
2. **Лист «Заказы» («Свод»)** — те же 13 колонок, считать **на суммах** по метке (месяц / день / итог) по его формулам:
   Выручка = Σ Выручка (без коэффициента), Себестоимость = Σ Себ-ть Реал, Маржа = Выручка − Себестоимость, М-ть = Маржа /
   Выручка, Реклама = Σ Реклама без НДС, ДДР = Реклама / Σ Выкуплено, Соинвест = (Σ без НДС − Σ с СПП) / Σ без НДС, Комиссия % =
   Σ Комиссия руб / Σ ₽, Гр.фин.рез = Σ Выкуплено − Σ Себ-ть × (Σ Выкуплено / Σ Выручка) − Реклама, Гр.фин.рез % = Гр.фин.рез /
   Σ Выкуплено, Цена = Σ ₽ / Σ шт. Блок WB — тем же кодом (коэффициент 49,81 % входит через «Выкуплено»).
3. **Приёмка:** (а) «Свод» = его формулы на Σ «Данных заказы» — 0,00 по 13 колонкам × все метки × обе площадки (прежняя
   приёмка переписывается на его формулы); (б) против книги 39-й: **Гр.фин.рез и Гр.фин.рез % по месяцам не меняются**
   (алгебраически k × (Выручка − СС) − Реклама = прежней формуле) — 0,00; ДДР %, М-ть %, Соинвест %, Оборот, шт, Цена, Комиссия %
   — 0,00; Выручка, Себестоимость, Маржа — ровно ÷ коэффициент (отношение = 1 / 0,6298 у Ozon, 1 / 0,4981 у WB) — таблицей;
   (в) «Данные заказы»: Σ Выкуплено / Σ Выручка по площадке = коэффициенту «Коэффициентов» до 0,0001. `docs/reports_model.md` §7б
   и лист «Примечания» — семантика источника по его формулам.

### §3. Статичные листы — сжать и дать «+/−» по месяцам (все листы формы: три Ozon, три WB, «Заказы»)

Фильтры теперь на листах «Сводная …», заглушки под них в статичных листах не нужны. Форма: строка 1 — подпись листа,
строка 2 — шапка (у листов выкупов Ozon — две строки: статьи и «Начисления / Ст-ть», как сейчас), данные с 3-й; пустых
строк и колонок (N–O у Ozon) нет; между блоками групп («× бренд», «по брендам» и т. п.) — одна пустая строка и строка
заголовка группы. **Дни — у всех месяцев**, не только у последнего: под строкой месяца его дни, сгруппированные Excel-ем
(`ws.row_dimensions.group(first, last, outline_level=1, hidden=True)`, `ws.sheet_properties.outlinePr.summaryBelow = False`,
чтобы «+» стоял у строки месяца сверху) — лист открывается свёрнутым до месяцев, любой месяц раскрывается плюсом; «Общий
итог» последним, вне групп. Ширины колонок по содержимому (числа с разделителями не должны резаться), закрепление шапки и
колонки A, форматы чисел как сейчас. Приёмка: строки месяцев и «Общий итог» = прежним 0,00 (Ozon — против `build_daily` и
тождеств 38-й, WB — против модуля как в 39-й); Σ дней каждого месяца = строке месяца (все месяцы, все листы, обе площадки);
тест на группировку — у каждого месяца `outline_level` дней = 1, у месяца и итога = 0. Листы «Сводная …», «Артикул»,
«Данные», «Коэффициенты», «Примечания» — не трогать (кроме §2).
