# Входящая задача

Сюда советник кладёт задачу для рабочей сессии. Сессия читает этот файл
и выполняет то, что в нём написано, а отчёт пишет в `docs/outbox.md`.

Порядок: одна задача за раз. Прежде чем взять новую, убедись, что по
предыдущей отчёт уже написан. Файл переписывается целиком, истории в
нём не копится — след остаётся в git.

Если задача противоречит правилам из `CLAUDE.md`, выполняется
`CLAUDE.md`, а расхождение описывается в отчёте.

### 3. Мерж FBO

Смержи `migrate-fbo-cursor` (коммит `de49122`) в `main`.

Мержим утром намеренно: Render катит из `main` автоматически, и нужен
целый день на наблюдение, а не ночь.

После первого сбора заказов на новом коде верни: сколько отправлений,
обращений к API, отказов 429, сколько заняло времени. Сравни с замером
из `docs/ozon_postings_migration.md` — 8 775 отправлений, 88 обращений,
0 отказов, 156 секунд.

### 4. Мелкая правка, не срочная

`loaders/ozon_fbo_orders_loader.py`, функция `posting_price`:
`return float(raw or 0)`. Валюту проверяем, а отсутствующий `amount` —
нет: если Ozon вернёт объект без `amount`, цена молча станет нулём.
Падать, а не обнулять.
