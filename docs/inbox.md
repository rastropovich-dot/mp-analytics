### §2. Фильтры образца — сбросить при пересадке

На «Сводная Ozon выкупы» после пересчёта: фильтр «Бренд» = KARATOV (один бренд), «Названия столбцов» = только «Комиссия»,
из значений видны только «Начисления». Это сохранённое состояние сводной второго кабинета (`pivotField` с `item h="1"`,
выбранный `item` у `pageField`, скрытые элементы поля столбцов), наложенное Excel-ем на наши элементы. Сделать в
`scripts/finrez_pivots.py`: у всех трёх сводных все `pageField` → «(Все)» (без выбранного `item`, `multipleItemSelectionAllowed`
как у владельца), у полей строк / столбцов / страниц снять `h="1"` со всех элементов (или очистить список `items` до
`<items count="1"><item t="default"/></items>` — Excel перестроит при refresh), оба поля данных видимы («Начисления» и
«Ст-ть продаж в себ-ти» у Ozon; семь денег у WB; 13 у заказов). Проверка в `finrez_excel_check.py`: после `refresh all` —
`current page` каждого поля страницы = «(All)», число элементов поля столбцов = 6 статей у Ozon, полей данных 2 / 7 / 13.

**Плюс — чужие значения в кэше (владелец увидел в фильтре «Бренд»: Pastel Cosmetics, Pastel (лаки), Carbon, FLAMINGO,
DEXCLUSIVE, (пусто) — бренды второго кабинета).** Мы опустошили `pivotCacheRecords`, но `sharedItems` у `cacheField`
в `pivotCacheDefinition` остались с их значениями (бренды, наименования, артикулы, SKU чужого кабинета), а сводная по
умолчанию хранит элементы, удалённые из источника. Сделать: у всех `cacheField` трёх кэшей `sharedItems` очистить (оставить
`<sharedItems/>` или с атрибутами типа без элементов — как принимает Excel, проверить на маленькой книге), в
`pivotTableDefinition` поставить `missingItemsLimit="0"`, `pivotField` без `items`. Проверка в Excel: элементы поля «Бренд» на
«Сводная Ozon выкупы» и «Сводная WB выкупы» = {KARATOV, Топаз, (без товара)} и ничего больше; «Артикул» / «Артикул
