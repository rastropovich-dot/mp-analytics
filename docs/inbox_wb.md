# Входящая задача — WB

Сюда советник кладёт задачу для рабочей сессии по Wildberries. Сессия
читает этот файл и выполняет то, что в нём написано, а отчёт пишет в
`docs/outbox_wb.md`. Правила обмена те же, что у Ozon-потока
(`docs/how-we-work.md`, раздел «Порядок обмена»): одна задача за раз,
файл переписывается целиком, пока задача в работе — советник его не
трогает; вопрос посреди задачи — в `outbox_wb.md` блоком «вопрос, задача
не закончена».

`docs/inbox.md` и `docs/outbox.md` — канал Ozon-сессии. Не читать как
задачу и не писать туда.
