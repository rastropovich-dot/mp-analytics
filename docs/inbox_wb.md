### 3. Лист «WB - месяц» и приёмка

`scripts/report_wb_month.py --month 2026-09 [--date-to]` → книга
`data/reports/wb_2026-09_to_<дата>.xlsx`, лист «WB - месяц» с колонками
владельца: Дата реализации (= `rrDate`), Оборот = Σ `retailPriceWithDisc`
(продажа − возврат), Комиссия = Оборот − `forPay` (**факт**, у него 44,4 %),
справочно «Комиссия по образцу 42 %», Выручка = (Оборот − Комиссия) / НДС −
(`ppvzReward` + `rebillLogisticCost`) × 22/122, Себестоимость (снимок 05-20 по
базовому артикулу; строка «без СС» — вслух, доля оборота), Маржа, Логистика =
`deliveryService` / НДС, Реклама = advert (сейчас 0, но колонка живая),
Эквайринг = `acquiringFee` / НДС, Прочее = (`paidStorage` + `penalty`) / НДС,
Фин. рез., Накладные в день 74 002,00 с датой действия (T81 листа), Ebitda.
НДС — тот же `VAT_RATES`. Индекс СС — тот же параметр, что у Ozon, если
владелец скажет; пока без него.

Приёмка `--check --xlsx ../mp-analytics/data/manual_report_september_20260922_v2.xlsx
--sheet "WB - сентябрь"` по образцу Ozon: колонка / у него / у нас / разница /
дней 0,00. Обязанные: Оборот, Выручка (с вычетом НДС за возмещение),
Эквайринг, Прочее — 21 из 21, кроме трёх дней, которые ты уже назвала
(эквайринг 09-03, 09-07; прочее 09-02) — они печатаются как расхождения с
суммой, чинить нечего, это его сторона. Комиссия — расхождение ожидаемое,
печатать обе. Логистика — печатать разницу по дням, правило его не искать
дальше одного часа. Себестоимость — разница, как у Ozon.
