# Входящая задача — WB

Сюда советник кладёт задачу для рабочей сессии по Wildberries. Сессия
читает этот файл и выполняет то, что в нём написано, а отчёт пишет в
`docs/outbox_wb.md`. Правила обмена те же, что у Ozon-потока
(`docs/how-we-work.md`, раздел «Порядок обмена»): одна задача за раз,
файл переписывается целиком, пока задача в работе — советник его не
трогает; вопрос посреди задачи — в `outbox_wb.md` блоком «вопрос, задача
не закончена».

`docs/inbox.md` и `docs/outbox.md` — канал Ozon-сессии. Не читать как
задачу и не писать туда.

### §3. Себестоимость WB по дате — подготовка (без изменения кода)

Ozon-сессия в сорок шестой загружает в `article_unit_costs` шесть снимков 1С (30.03, 06.04, 20.04, 29.04, 12.05, 20.05) и делает общую
функцию «себестоимость на дату продажи»; WB подключит её отдельной задачей после их мержа. Сейчас — оценка по файлам снимков
(`~/Downloads/Telegram Desktop/ChatExport_2026-09-29 (2)/files/СС 30.03.26.xlsx` … `СС 20.05.26.xlsx`; шапки ключей WB в разных файлах
разные — по имени колонки): каким ключом модуль WB ищет себестоимость сейчас (`load_costs`, базовый артикул), покрытие ключей WB-строк
окна в каждом снимке, и **таблица по месяцам апрель … сентябрь: себестоимость WB было (20.05) → стало бы (по дате), фин. рез. было →
стало бы**. Медиана советника по ключам Ozon: 30.03 … 20.04 ≈ 1,12 к 20.05, 29.04 и 12.05 ≈ 1,07 — у WB ожидается тот же порядок.
