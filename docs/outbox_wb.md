2. **`buyout_rate` WB после смены правила** (1,005 на плато, 1,843 в окне) — что ещё
   зависит от `orders_qty` / `orders_amount_seller` WB, по коду:
   * `reports_daily_sku_kpi.py`: `buyout_rate = buyouts_qty / orders_qty`,
     `ad_share_of_orders = ad_spend / orders_amount_seller`, `ad_share_orders =

     карты sku → article — уже по `orders_qty + cancelled_orders_qty` (созданные);
   * `reports_daily_marketplace_kpi.py`: те же четыре плюс `ad_share_revenue`;
   * `alerts_telegram.py`: «WB вчера: Заказы», отклонение к 7 дням, триггер
     риска «заказы ниже среднего» и срез «сегодня против вчера» — все по
     funnel-overlay (созданные из `marketplace_orders_analytics`), витрину не
     читают — их правило не тронуло; выкупы алерта — из `marketplace_buyouts`;
   * остальные читатели `orders_qty` (`report_7_days`, `report_60_days`,
     `export_management_excel`, `report_management`, decision-скрипты) — витрину
     как есть, без своего знаменателя.

   `buyout_rate = buyouts_qty / (orders_qty + cancelled_orders_qty)`, то есть

   продажах) — правильнее, но это другой показатель и отдельная задача. Пока

### 5. Что WB называет `isCancel` — не установлено, вопрос

Документация (dev.wildberries.ru → Отчёты → `GET /api/v1/supplier/orders`,
прочитана 2026-09-21) дословно: `isCancel` — «Отмена заказа: true — заказ

По данным (3 538 отмен на 29 датах): в день заказа 34,7 %, 1–2 дня 18,0 %, 3–7

покрывает и отказ при получении, — по смыслу, не по документу. Записано в
`docs/wb_orders_write_window.md`. **Вопрос владельцу/советнику:** кто-нибудь знает
по кабинету WB, входит ли отказ на ПВЗ в отмену? Правило от ответа не меняется,
меняется чтение `cancelled_orders_*` у WB: «не выкуплено по любой причине» против
«отменено до отправки».

лимит 1 запрос в минуту, 1 строка = 1 заказ = 1 единица товара.
