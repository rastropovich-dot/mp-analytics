## Выкупы WB


| Финотчёт (выкупы) | Финансовые отчёты → Отчёты о реализации → Ежедневные → дата |
|---|---|

Берем ежедневно.
Нам нужны столбцы:
Дата продажи – по ней выстраивается вся аналитика
Дата заказа покупателем – нужна для сс
Цена розничная с учётом согласованной скидки = ТО – вычесть комиссию и НДС
Компенсация платёжных услуг/комиссия за интеграцию платёжных сервисов = Эквайринг и комиссия за платежи
Услуги по доставке товара покупателю
Общая сумма штрафов (Прочее)
Хранение
Удержания (Прочее)
Если сс меняется, то добавляем доп. Столбец СС и подгружаем её только для Продажа и Возврат в столбце Обоснование для оплаты. СС берем на дату заказа, без НДС
Из этих данных делаем свод.

*[скриншот 4 — в исходном .docx]*

Возмещение издержек не надо. Площадка тоже.
Столбцы A-H, O, P из таблицы.
Зеленые – расчетные
Прочее без НДС = (сумма штрафов+хранения+удержания)/1,22
Эквайринг без НДС = эквайринг/1,22
Логистика без НДС = услуги по доставке товара/1,22
Выручка = (Цена розничная с учётом согласованной скидки - Цена розничная с учётом согласованной скидки умножаем на 0,NN (значение комиссии) и очищаем от НДС, делим на 1,22)
Например (Цена розничная с учётом согласованной скидки - Цена розничная с учётом согласованной скидки*0,33)/1,22
ВНИМАНИЕ!
Если был Возврат – фильтр по Обоснование для оплаты, то в поле Цена розничная с учётом согласованной скидки, нужно в изначальной таблице заминусить цену и СС.
Далее это собираем в таблицу Выкупы WB. 
Рекламу забираем по аналогии с Заказами, ту же.
ВБ в конце еженедельного отчета учитывает рекламу, но мы её уже учли отдельно. Её нужно проверить и не задублировать!
Оказание услуг ВБ продвижение в поле Виды логистики штрафов её надо не учитывать.
