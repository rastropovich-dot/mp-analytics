# Чат разработчиков Ozon

`ozon-dev-chat.json` — экспорт публичного чата Ozon for dev из Telegram.

    чат        General (public_supergroup), id 1677162135
    сообщений  37 986 (базовый экспорт 37 863 + 123 новых)
    период     2022-05-13 … 2026-09-15
    пропусков  нет ни одного месяца
    снято      2026-09-13, дополнено 2026-09-15

## Зачем

Источник ответов о поведении Ozon API: недокументированные ограничения,
реальные сроки отключения методов, ответы поддержки, обходные пути.
Брать ответы отсюда, а не спрашивать владельца.

Второй источник рядом — `spec/` с OpenAPI-спеками. Спека говорит, что
метод обещает; чат говорит, как он ведёт себя на самом деле.

## Как искать

Файл большой (30 МБ), целиком не читать. Искать по нему скриптом:
фильтровать `messages` по подстроке в `text`, возвращать дату, автора
и текст. У каждого сообщения есть `id` — по нему сообщения связываются
через `reply_to_message_id`, так что ветку обсуждения можно собрать.

Поле `text` бывает строкой, а бывает списком фрагментов (когда есть
ссылки или код) — обрабатывать оба случая, иначе часть сообщений
потеряется при поиске.

## Вложения

Пути в полях `photo` и `file` заданы относительно корня экспорта.
Корень лежит вне репозитория, на машине владельца:

    ~/Downloads/Telegram Desktop/ChatExport_2026-09-13/

    result.json                                    сам экспорт (копия здесь)
    chats/chat_562951630583447/topic_1/photos/     2 520 фото, 134 МБ
    chats/chat_562951630583447/topic_1/files/        476 файлов, 34 МБ
    chats/chat_562951630583447/topic_1/voice_messages/   1 файл

Всего 200 МБ. В репозиторий не кладём — здесь только JSON.

Чтобы открыть вложение: взять путь из поля `photo` или `file` и
приписать к нему корень выше.

72 файла не выгрузились из-за ограничения на размер — в JSON у них
вместо пути стоит текст в скобках.

Папка в Загрузках недолговечна. Если её удалить, картинки пропадут, а
JSON останется со ссылками в никуда — тогда понадобится новый экспорт.

## Обновление

Экспорт — снимок на дату, сам не обновляется. Переснимать вручную:
Telegram Desktop → чат → меню → Экспорт истории чата → формат JSON.
Новый экспорт дописывать к старому по `id`, не заменять целиком.

Так и сделано 2026-09-15: инкремент за 09-07 … 09-15 (494 сообщения,
id 65419 … 66090) слит с базой по `id`. Новых 123, пересечение 371, из
них 17 изменились задним числом — на пересечении побеждает свежий
снимок. Резервная копия перед слиянием — `ozon-dev-chat.json.bak`
(в `.gitignore`), сам инкремент — `_increment_20260915.json` (там же).

То, что 17 сообщений из 371 изменились, стоит помнить: чат
редактируется задним числом, поэтому слияние не «дописать хвост», а
«обновить пересечение и добавить новое».
